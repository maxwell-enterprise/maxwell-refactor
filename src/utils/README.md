# utils

Cross-feature utility functions.

## shared/

| File | Purpose |
|------|---------|
| **dataUtils** | ID generation, date formatting (Postgres-compatible) |
| **devDatabase** | IndexedDB wrapper for mock/local-first storage |
| **excelHelper** | Excel import/export with validation |

Compatibility re-exports remain at `utils/dataUtils`, `utils/devDatabase`, `utils/excelHelper`.
